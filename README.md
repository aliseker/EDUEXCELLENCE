# EDU Excellence - Education Management System

Modern bir eğitim yönetim sistemi. KA1 kursları, KA2 projeleri, blog, iletişim ve daha fazlası...

## 🚀 Teknolojiler

### Backend
- .NET 8.0 Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- MailKit (Email)

### Frontend
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- React Hot Toast
